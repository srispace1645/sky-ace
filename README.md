# Sky Ace

A fighter plane dogfight game that runs in any web browser, including the Tesla touchscreen browser.

**Play:** https://srispace1645.github.io/sky-ace/

- Red planes hunt you and shoot back. Yellow planes run away, so chase them down.
- Touch: drag on the left side to steer, FIRE and BOOST buttons on the right.
- Keyboard: arrow keys to steer, Up to boost, Space to fire, M for sound.
- Works offline after the first visit (thanks to `sw.js`).
